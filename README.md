# Foundation Medical: The Heart Hospital

Welcome to the digital foundation of **The Heart Hospital**, a premier cardiovascular center under the **Foundation Medical** network. This repository serves as the core web application for patient engagement, clinical risk assessment, and interactive health assistance.

## Project Overview

The Heart Hospital application is designed to provide a modern, responsive, and patient-centric experience. Built using the **Foundation for Sites** CSS framework, it ensures accessibility and high performance across all devices.

### Key Features

- **Heart Health Risk Assessment**: A data-driven tool for patients and clinicians to evaluate cardiovascular risk factors.
- **AI Health Assistant**: A simulated AI-powered chatbot to provide instant answers to heart health inquiries.
- **Patient Portal Mockup**: A responsive interface for patients to track their cardiovascular metrics and history.
- **Modern Medical Design**: A clean, professional UI optimized for healthcare environments.

## Technologies Used

- **Foundation CSS Framework**: For responsive grid layouts and UI components.
- **Vanilla JavaScript**: For interactive logic and AI simulation.
- **HTML5/CSS3**: For structured and styled content.

## Getting Started

To run the application locally, simply open the `index.html` file in any modern web browser. No complex build steps are required for the frontend.

```bash
# Clone the repository
git clone https://github.com/attahzoe78/Foundation-Medical-The-Heart-Hospital.git

# Navigate to the project directory
cd Foundation-Medical-The-Heart-Hospital

# Open the landing page
open index.html
```

## Testing

Functional tests for calculation logic can be found in the `tests/` directory.

```bash
# Run logic tests
node tests/test_logic.js
```
